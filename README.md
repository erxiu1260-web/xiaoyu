# 🐱 小猫去找小鱼

送给小鱼的闯关小游戏：一只粉色小猫一路吃小鱼，去找在路尽头等她的小狗。

## 直接玩

用手机或电脑打开下面的链接就能玩，可以直接发给别人。

| 版本 | 链接 | 内容 |
|---|---|---|
| **第 2 版（最新）** | **https://erxiu1260-web.github.io/xiaoyu/v2/** | 在第 1 版基础上加了蘑菇蹦床、空中台子、猫薄荷、爱心泡泡、情话鱼、小鱼雨、连击 |
| 第 1 版 | https://erxiu1260-web.github.io/xiaoyu/v1/ | 最早的版本：5 关闯关、吃小鱼、露珠彩蛋、告白结局 |

## 文件在哪

| 文件 | 是什么 |
|---|---|
| `v2/index.html` | 第 2 版游戏 |
| `v1/index.html` | 第 1 版游戏 |

每个版本都只有一个文件。下载下来，用浏览器打开也能玩。

## 注意

- 在 github.com 上点进这些文件，看到的是源代码，玩不了。要玩游戏，请打开上面 **github.io** 结尾的链接。
- 改完代码后，GitHub 要 1～2 分钟才会更新网页。如果打开显示 404，等一会儿再刷新。
- 以后有新版本，会放进新的文件夹，例如 `v3/`。旧版本不会删掉。
- 以前的旧链接（`erxiu1260-web.github.io/--online/xiaoyu/...`）会自动跳转到这里。
